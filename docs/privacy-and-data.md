# 사생활 보호와 데이터 보존

## 앱 잠금

첫 실행에서 8~128자 비밀번호를 두 번 입력하거나 나중에 설정할 수 있다. 활성화 후에는 시작할 때 인증을 거쳐야 한다. **설정 → 사생활 보호**에서 현재 비밀번호를 확인해 변경·해제하고, 지금 잠그기로 재생 중지·음량 0%·잠금 화면 전환을 수행한다.

현재 구현은 앱 시작과 수동 잠금을 다룬다. 최소화·일정 시간 경과의 자동 잠금, OS 스크린샷 차단, 파일 암호화는 구현된 기능으로 안내하지 않는다. Esc는 음량 0%와 최소화이며 비밀번호 잠금과 다르다.

[PrivacyLock](../lib/privacy_lock.dart)은 무작위 32바이트 salt와 PBKDF2-HMAC-SHA256 600,000회 검증값을 저장한다. Windows는 별도 isolate에서 시스템 CNG를 호출하고 검증값은 상수 시간 비교를 사용하는 라이브러리로 비교한다. 비밀번호 원문을 설정·로그·백업에 저장하지 않는다.

5회 연속 오입력 후 30초부터 최대 5분의 재시도 제한이 적용되며 DB에 남아 재시작 후에도 유지된다. 변경·해제도 현재 비밀번호 검증을 통과해야 한다. 손상된 잠금 정보는 라이브러리를 열지 않는 오류 상태로 처리한다.

이 기능은 앱 접근 보호다. 같은 OS 계정에서의 파일 접근·변조, 원본 영상·카탈로그 암호화까지 보장하지 않는다. 비밀번호 복구·우회 기능은 없다. 잠금 DB를 삭제하는 방법을 일반적인 암호 복구 기능으로 문서화하지 않는다.

## 저장과 백업의 경계

| 자료 | 위치·역할 | 카탈로그 JSON 백업 |
| --- | --- | --- |
| 원본 영상 | 사용자가 연결한 실제 폴더 | 포함하지 않음 |
| `vault.sqlite` | 앱 지원 데이터 경로, 폴더·메타데이터·설정·기록 | 내보내기 스키마의 메타데이터 포함 |
| 장면·컬렉션·규칙·이어보기 | 카탈로그의 연결 정보 | 포함 |
| 썸네일·미리보기·프로필 이미지 파일 | 별도 파일/캐시 | 파일 바이트를 묶는 백업이 아님 |
| `privacy.sqlite` | 카탈로그와 별도인 잠금 정보 | 포함하지 않음 |
| 앱 실행 폴더 | EXE·DLL·data·tools | 사용자 데이터 저장소와 별개 |

앱 지원 경로는 `path_provider`에서 결정한다. 사용자 경로를 코드·공개 문서에 고정하지 않는다. 다른 기기로 카탈로그를 옮길 때 원본·외부 이미지·경로·권한과 새 기기의 잠금 설정을 별도로 확인한다.

## 파일 변경과 복원

폴더 연결 해제는 원본 삭제가 아니다. 기존 이미지 카탈로그 기록은 영상 목록에서 숨기되 백업과 원본 파일을 보존한다. 영상 이동은 실제 파일을 바꾸는 작업이므로 충돌·복사 무결성·취소·부분 실패를 명시한다.

백업 복원은 읽기 실패·알 수 없는 형식·잘못된 참조에 기존 카탈로그를 유지해야 한다. 복원 전 보호 사본과 정상 왕복을 검사한다. 카탈로그 백업 성공을 원본 영상 전체의 백업 성공으로 안내하지 않는다.

DB 비교는 일관된 스냅샷 또는 앱을 종료하고 필요한 WAL까지 포함한 상태로 수행한다. 데이터베이스 파일을 실행 중 임의로 하나만 복사해 완전한 복구본이라고 하지 않는다. 실행 파일 되돌리기와 스키마·데이터 되돌리기는 별개다.

## 검증과 기록

[privacy_lock_test.dart](../test/privacy_lock_test.dart)는 검증값·salt·재시작·동시 시도·변경/해제·백업 분리를 검사한다. [privacy_flow_test.dart](../integration_test/privacy_flow_test.dart)는 gate·UI·대기·오류·재생 중 잠금을 검사한다. 설치 사본 진단은 배포된 CNG·SQLite 경로를 확인한다.

시험 비밀번호는 임시 데이터에만 사용한다. 공개 캡처·로그에는 사용자 영상 제목·실제 경로·비밀번호·개인키·인증 토큰을 넣지 않는다. 원격 SSH 공개키 등록과 앱 시작 비밀번호는 별개이며, 전역 접속 정보는 저장소 밖에서 관리한다.


## AI 정보 교환과 배우 이미지

AI 요청문 복사는 모든 영상의 파일명·제목·배우·태그·설명을 포함하며, 사용자가 외부 AI에 직접 전달한다. 전체 경로·개인 메모·평점·재생 기록·영상 파일은 포함하지 않는다. 앱이 외부 AI에 자동 업로드하지 않는다.

반환된 배우 이미지 주소에서 **이미지 불러오기**를 누르면 해당 HTTPS 서버로 다운로드 요청이 전송된다. 서버에는 일반 네트워크 연결 정보가 전달된다. 이미지 적용을 체크하고 저장하면 검증된 PNG 파일을 앱 데이터의 `actor-images`에 보관한다. 카탈로그 JSON 백업은 이 파일의 바이트를 포함하지 않으므로 다른 기기로 옮길 때 이미지 파일도 별도로 보존해야 한다.
