# Soft Vault 0.3.2

영상 목록과 재생 조작부를 간결하게 정리하고, 재생 중 평점 입력과 필터 표시를 수정했습니다.

## 바뀐 동작

- 파일 카드는 썸네일을 키우고 제목·배우·태그를 세 줄로 배치했습니다. 시간·폴더와 별점은 오른쪽에 정렬됩니다. 체크박스와 재생 중 문구는 제거했습니다.
- 파일 수 옆에서 정렬과 필터를 조작할 수 있습니다. 재생 중에도 활성 필터를 확인하고 해제할 수 있습니다.
- 재생 버튼의 테두리와 하단 단축키 안내를 없애고 간격과 높이를 조정했습니다. 단축키 기능은 유지됩니다.
- 재생바의 별을 누르면 해당 영상에 바로 평점을 저장합니다. 다른 파일을 선택해 놓아도 숫자 평점 단축키와 초기화는 재생 중인 영상에 적용됩니다.
- 여러 파일 선택을 제거했습니다. 파일 메뉴에는 상세정보·파일 위치 열기·파일 이동·휴지통으로 이동이 남습니다. 재생은 더블클릭하고, 정보 편집과 원본 파일 이름 변경은 상세정보에서 할 수 있습니다.

## 설치와 업데이트

Windows x64 설치 EXE와 Apple Silicon Mac DMG를 제공합니다. 기존 앱의 **설정 → 앱 정보 · 업데이트**에서도 업데이트할 수 있습니다. `.svupdate` 두 개와 `update.json`, `update.json.sig`는 앱 내 업데이트용입니다.

[0.3.2 정식 릴리즈](https://github.com/poyal/soft-vault/releases/tag/v0.3.2)에서 내려받을 수 있습니다. Windows·Mac 설치 검증을 마쳤으며 공개 파일 8개를 다시 내려받아 크기·SHA-256 일치를 확인했습니다. 파일 고정값은 [파일 목록](release-assets.json)에 있습니다.

Windows는 코드 서명이 없으며 Mac은 로컬 서명입니다. Apple Developer ID 서명·공증은 없습니다. [설치 안내](../../../README.md#설치와-첫-실행)를 참고해 주세요.

검사 결과와 미검증 범위는 [검증 기록](VERIFICATION.md)에 별도로 기록합니다.
