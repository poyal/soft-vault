## 탐색과 종료

재생 중 같은 지점을 다시 눌렀을 때 두 장비 모두 30회 중 30회 목표 프레임을 표시했습니다. 연속 이동 중 닫았을 때의 이어보기 보존은 두 장비 모두 0/30회에서 30/30회로 개선됐습니다. Windows UHD 630의 4K60 HEVC와 Mac M4의 일부 연속 입력에서는 구간 이동 뒤 화면 정지가 남았습니다. [측정 방법·기존판 비교·개별 결과](../../verification/2026-11-23-playback-recovery.md)

## 검증 중 확인한 사항

Mac 카탈로그 테스트에서 SQLite 조회가 끝나기 전에 첫 화면의 선택 항목을 읽어 실패했습니다. SSH와 로그인 세션에서 재현됐습니다. 테스트가 실제 초기화를 기다린 뒤 같은 ID를 검증하도록 수정했고 Mac 로그인 세션에서 통과했습니다.

Windows에서도 수정한 테스트를 별도로 재실행해 통과했습니다. Mac의 첫 패키징에서는 격리 폴더에 서드파티 라이선스 고지가 빠진 것을 발견했습니다. 기존 Mac 소스에서 Windows 후보와 내용 해시가 일치하는 고지를 복원하고 같은 Release 앱으로 패키징을 재개했습니다.

## 배포 후보에서 실행한 검사

- 두 OS에서 정적 분석과 기본 테스트 123개가 통과했습니다. 기본 실행에서는 각 OS에 해당하지 않는 테스트 1개와 외부 HTTPS 이미지 테스트 1개가 생략됐습니다. Windows에서 HTTPS 이미지 테스트는 별도로 실행해 통과했습니다.
- 두 OS에서 실제 카탈로그·재생·코덱·잠금·사용자 시나리오, 스트레스 및 1만 파일 검사, 프로파일 모드의 UI·크기 변경·재생 이력 검사를 실행했습니다. 구간 이동과 닫기 전 이어보기 회귀도 각각 통과했습니다.
- 두 OS에서 일반·반복 닫기 18회와 업데이트 도우미의 설치·복구·잘못된 패키지 처리 5건을 각각 통과했습니다.
- Windows x64 설치 EXE로 새 설치와 재설치, 시작 메뉴, 실제 재생, 제거 및 카탈로그 데이터 보존을 확인했습니다. Windows 화면 비교도 후보에서 생성한 화면으로 재실행했습니다.
- Mac arm64 DMG를 마운트하고 앱을 복사해 로컬 서명과 ZIP 설치본의 파일별 해시를 대조했습니다. Windows EXE와 Mac DMG에서 설치한 앱으로 영상 자료 11종을 각각 재생했습니다.
- 두 업데이트 파일의 크기와 SHA-256은 설치 진단에 사용한 각 ZIP과 일치했습니다. 0.3.4와 같은 공개키로 앱의 검증 코드를 실행해 Ed25519 서명과 두 플랫폼의 다운로드 주소를 확인했습니다.

별도의 30분 연속 재생과 기존 카탈로그 전체를 사용한 0.3.4 설치본 업그레이드는 이번 릴리즈에서 실행하지 않았습니다. [배포 파일별 SHA-256](README.md#배포-파일)
