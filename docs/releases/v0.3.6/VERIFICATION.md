2026년 11월 27일 15시 57분(한국 시간)에 최신 정식 릴리즈로 공개했습니다. 초안에서 내려받은 파일 8개와 공개 후 로그인 없이 다시 내려받은 파일 8개가 모두 검증 원본과 크기 및 SHA-256이 일치했습니다. [GitHub 릴리즈](https://github.com/poyal/soft-vault/releases/tag/v0.3.6) · [파일별 공개 다운로드 검증 결과](publication-verification.json)

제품 소스는 `9983d8db2054e5ecbf8340537dfb36964596a4f2`입니다. Windows x64와 Apple Silicon Mac의 빌드 전 소스 지문은 `08e86c892dfa43aa2f710acfbd2ddc2932cc8a462ef6be713316d2042c3c7c52`로 일치했습니다.

## 수정한 문제

Mac mini M4에서 0.3.5의 재생 중 또는 구간 이동 중에 앱 종료 요청을 연속으로 보내자 4회 중 2회가 비정상 종료됐습니다. 이제 앱이 첫 종료 요청을 처리하는 동안 후속 요청을 합치고, 이어보기 저장과 재생기 해제가 끝나면 AppKit에 종료를 전달합니다.

종료 검사에서는 임시 카탈로그와 시험 영상을 사용합니다. 반복 종료 시나리오는 첫 번째 종료 요청에 응답하기 전에 두 번째 요청을 보냅니다. 검사 도구는 프로세스 종료 코드와 시간, Flutter에 전달된 종료 요청 횟수, 재생기 해제 기록, 종료 후 SQLite에서 다시 읽은 이어보기 위치를 대조합니다.

## 설치 파일과 자동 업데이트

- Windows 설치 EXE로 새 설치와 재설치, 시작 메뉴 등록, 실제 재생, 제거를 확인했습니다. 제거 후 시험용 사용자 데이터가 보존됐고, 설치된 앱 파일 42개의 해시가 일치했습니다.
- Apple Silicon Mac DMG를 마운트하고 응용 프로그램 폴더 링크를 확인했습니다. 복사한 앱의 로컬 서명과 파일별 해시가 검증된 ZIP의 설치 사본과 일치했습니다. Windows EXE와 Mac DMG에서 설치한 앱으로 각각 영상 11종을 재생했습니다.
- 두 플랫폼 모두 검증 전후 소스 지문이 일치했습니다. 설치 검사에 사용한 ZIP과 업데이트 파일의 크기·SHA-256이 일치했고, 앱의 업데이트 검증 코드로 0.3.5와 같은 공개키, Ed25519 서명, 대상 버전과 플랫폼별 URL을 확인했습니다.

이번 검사에는 기존 사용자 카탈로그 전체를 이용한 0.3.5 업그레이드와 장시간 연속 재생이 포함되지 않았습니다. [배포 파일별 크기와 SHA-256](README.md#배포-파일)
