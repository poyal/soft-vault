# 0.2.1 Windows·Mac 검증

버전 `0.2.1+3`. 폴더 등록 지연 수정의 두 플랫폼 릴리즈를 준비한다. 실제 완료된 결과만 아래에 기록한다.

| 항목 | Windows x64 | macOS arm64 |
| --- | --- | --- |
| 동일 소스 지문 | NOT_RUN | NOT_RUN |
| 정적 분석·일반 회귀 | NOT_RUN | NOT_RUN |
| 빠른 폴더 연결·썸네일 중지 UI | 0.2.0 로컬 수정 코드 검사 통과, 버전 변경 전 | NOT_RUN |
| 종료·업데이트 도우미 | NOT_RUN | NOT_RUN |
| Release 빌드 | NOT_RUN | NOT_RUN |
| ZIP 설치 사본·재생 | NOT_RUN | NOT_RUN |
| EXE·DMG 내용 검증 | NOT_RUN | NOT_RUN |
| 서명된 업데이트 파일 | NOT_RUN | NOT_RUN |
| 게시 후 공개 다운로드 해시 | NOT_RUN | NOT_RUN |

앞선 Windows 조사 결과는 [폴더 로딩 수정 기록](../../verification/2026-11-10-folder-loading.md)에 보존한다. 공개 버전의 실제 소스·검사·자산 해시는 이번 실행 결과로 채운다.
