# Soft Vault 0.1.0

컴퓨터의 영상을 재생하고 배우·태그·평점으로 정리하는 첫 배포본이다. [다운로드](https://github.com/poyal/soft-vault/releases/tag/v0.1.0)에는 저장소 접근 권한이 필요하다.

## 사용할 수 있는 기능

- 영상 폴더 연결, 검색·필터, 배우·태그의 전체 항목, 목록·그리드 보기.
- 클릭 재생·일시정지, 이어보기, 트랙·자막·배속, 전체화면. 새 영상은 음량 0%로 시작하며 Esc는 음소거 후 최소화한다.
- 상세정보 보기와 명시적 편집, 장면 북마크·메모, 대표 썸네일, 무음 미리보기.
- 스마트 컬렉션, 중복 비교, 검증 복사 이동과 복구, 이동 규칙, NFO 연동, 카탈로그 백업·복원.
- 통합 설정과 앱 시작 비밀번호. 비밀번호는 앱 접근을 보호하며 원본 영상을 암호화하지 않는다.

Windows에서 최대화 상태로 전체화면을 종료할 때 목록이 숨은 채 남는 문제를 수정했다. Mac은 전체화면 전환 완료를 기다려 최소화하고, 복원하면 일반 창으로 돌아온다. Mac의 `/var`와 `/private/var` 경로가 다른 파일로 취급되는 문제도 수정했다.

## 설치

| 파일 | 검증 환경 | 크기 |
| --- | --- | ---: |
| `SoftVault-0.1.0-windows-x64.zip` | Windows 11 Pro, x64 | 113,814,352 bytes |
| `SoftVault-0.1.0-macos-arm64.zip` | macOS 27.0.1, Apple M4 | 83,308,912 bytes |

Windows는 ZIP 전체를 풀고 `app/soft_vault.exe`를 실행한다. 선택 사항인 `Install.ps1`은 사용자 폴더 설치와 시작 메뉴 등록용이다. Mac은 압축을 풀고 `Soft Vault.app`을 응용 프로그램 폴더로 복사한다. 별도 Flutter·FFmpeg·코덱 팩은 필요하지 않다.

Windows 실행 파일은 코드 서명이 없고, Mac 앱은 로컬 서명이며 Apple Developer ID 서명·공증은 없다. Mac 실행이 차단될 때의 안내와 모든 기능의 실제 화면은 [사용자 매뉴얼](../../../README.md)에 있다. 기존 카탈로그 백업은 영상 원본이나 잠금 정보를 포함하지 않는다. 이전 공개 배포본이 없어 구버전 설치본 업그레이드는 검사하지 않았다.

## 검증 범위

Windows 99개, Mac 100개 검사가 통과했다. 두 OS 각각 네이티브 UI E2E 32개와 별도 최적화 모드 검사 4개를 포함해 확인했으며, 최종 ZIP 설치 사본에서도 DB·잠금·이동·썸네일·재생·11종 코덱을 검사했다. Mac은 일반 앱 실행 경로인 LaunchServices도 확인했다. 세부 집계·수치·소스 대응·제한은 [검증 기록](VERIFICATION.md)과 [결과 JSON](results.json)에 있다.

HDR 파일 디코딩은 확인했지만 물리 디스플레이의 HDR 밝기·색 출력, 스피커 출력, 실제 OS 파일 선택창·IME, 수시간 연속 재생을 검증한 것은 아니다. 플랫폼 글꼴·렌더러 차이가 있어 시안과 픽셀 단위 완전 일치를 주장하지 않는다.
