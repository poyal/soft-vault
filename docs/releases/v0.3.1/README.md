# Soft Vault 0.3.1

## 바뀐 동작

- 파일 카드를 한 번 클릭하면 선택하고, 두 번 클릭하면 재생합니다. 다른 파일을 선택해도 재생 중인 영상은 유지됩니다.
- 영상 목록과 재생 영역 사이의 경계를 드래그해 목록 폭을 조절할 수 있으며 다음 실행에서도 설정을 유지합니다.
- 파일 메뉴에서 상세정보, 정보 편집, 파일 위치 열기, 이름 변경, 이동, 휴지통 이동을 실행할 수 있습니다.
- 상세정보에서 편집 화면에 들어가지 않고 평점을 저장하고 검색으로 태그를 지정할 수 있습니다.
- 재생 횟수·최근 재생 시각·이어보기·완료 상태는 유지하며 날짜별 재생 이력 화면은 제거했습니다. DB 이전 전에 복구 사본을 만듭니다.
- 업데이트 교체 중 일시적인 파일 잠금을 재시도하고 실패 단계와 오류를 표시합니다. 버전 표시는 `0.3.1` 형식으로 통일했습니다.
- 빠르게 영상을 전환할 때 파일 정보 조회가 재생 요청 순서를 바꾸지 않도록 처리했습니다.
- 재생 화면의 단축키 표시가 가로 전체로 늘어나는 문제를 수정하고 검색 버튼에 단축키 안내를 추가했습니다.

## 설치와 업데이트

Windows x64 설치 EXE와 Apple Silicon Mac DMG를 제공합니다. 앱 내 업데이트용 `.svupdate`, `update.json`, `update.json.sig`는 앱이 사용합니다.

구버전 업데이트 도우미가 교체에 실패하는 경우 새 설치 프로그램으로 기존 위치에 재설치해 주세요. 사용자 라이브러리는 앱 설치 폴더와 별도로 보관됩니다. DB v5는 재생 요약을 유지하며 이전 날짜별 이력을 제거하므로 이전 앱 실행 파일만 덮어쓰는 방식으로 DB가 되돌아가지는 않습니다.

Windows 코드 서명과 Apple Developer ID 서명·공증은 제공하지 않습니다. Mac 번들은 로컬 무결성 서명을 사용합니다.
