# Soft Vault 0.3.0

현재 릴리즈 후보입니다. 게시·파일 정보는 검증 후 기록합니다.

- 글자 크기·대비, 목록 카드의 경계·선택 표시를 개선했습니다.
- 설정·조회조건·메타데이터 등 전체 화면을 공통 테마와 버튼 규칙에 맞춰 정리했습니다.
- 전체 폴더 새로고침은 설정 옆 아이콘으로 이동하고 필터·정렬 영역을 정리했습니다.
- 영상 재생 중 방향키 탐색이 포커스 이동이나 음량 변경을 함께 일으키지 않도록 수정했습니다.
- 설정의 메타데이터 화면에서 AI 반환 정보를 검토하고 배우 이미지도 미리보기 후 선택하여 등록할 수 있습니다.
- Windows 디버그 테스트에서 재사용된 프로세스 ID의 오래된 미디어 캐시로 발생하던 충돌을 방지했습니다.
