## 설치 사본에서 확인한 것

개발 도구가 없는 PATH를 사용하고 개발용 SQLite DLL을 잠시 격리했으며, 검사 후 복원했다. 이는 같은 PC의 격리 설치 사본 검사이지 개발 도구가 한 번도 설치되지 않은 깨끗한 VM 검증은 아니다. 전체 Flutter UI E2E를 이 ZIP의 외부 UI 검사로 수행한 것도 아니다.

## 화면·성능의 기존 근거

개발 PC는 i7-8700B 6코어/12스레드, RAM 63.8GiB, UHD 630이다. 렌더러·아이콘 A/B 검사에서 동일 4영상 탐색 raster P95는 기존 29.792ms에서 Skia와 SVG 색상 직접 지정 적용 후 4.989ms로 줄었다. 이후 실제 창 내부 크기를 보정한 일반 UI 측정에서 CPU 평균 2.29%, 측정 최대 5.83%, GPU 엔진 측정 최대 46%, 전용 작업 메모리 최대 205.2MiB였다. 작업·표본·모드가 정해진 해당 PC의 결과이며 모든 GPU의 성능 보장은 아니다.

실제 창에 가상 캔버스가 비율 축소되던 E2E 설정을 제거하고 내부 화면 크기·DPI·변환을 검사했다. 영상 종횡비 여백은 유지한다. 원본 HTML과 실제 앱의 픽셀 차이는 남아 있으며 100% 디자인 일치 완료로 표시하지 않는다.
