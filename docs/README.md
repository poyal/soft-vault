## 현재 확인된 범위

- 소스 버전은 `pubspec.yaml`의 `0.1.0+1`이다. 이 번호만으로 공개 릴리즈가 존재한다고 판단하지 않는다.
- Windows 개발 PC에서 누적 검사 99개, 별도 profile 실행 4개, ZIP 설치 사본 검증 결과가 있다. 서로 다른 시각의 실행을 합친 기록이며 단일 고정 커밋의 전체 인증은 아니다.
- Mac M4와 별도 RTX Windows PC는 SSH 인증을 확인했다. 해당 기기의 앱 빌드·E2E·HDR 출력 통과를 의미하지 않는다.
- Mac용 준비·검증·ZIP 패키징·설치 검사 스크립트와 소스 지문 도구를 추가했다. Apple Developer ID 서명·공증과 자동 게시 파이프라인은 없다. 스크립트 존재와 개별 후보 통과는 구분한다.

현재 결과의 출처·해시·한계는 [2026-11-08 Windows 검증 기록](verification/2026-11-08-windows.md)에 보존한다. 앞으로 새 후보는 템플릿의 모든 항목을 `NOT_RUN`에서 시작한다.

## 문서의 지위

공통 가이드는 운영 기준이며 그 자체가 검사 통과 증거는 아니다. `현재 구현`, `수동 절차`, `미구현`, `미검증`을 구분한다. 다른 프로젝트의 도구·테스트 수·게시 예외를 Soft Vault의 구현이나 권한으로 가져오지 않는다. 후속 빌드·원격 검증·게시 결과는 별도 검증 기록에 남긴다.

`build/`의 로그·캡처·ZIP은 로컬 생성물이다. 해당 링크는 결과를 생성한 작업 공간에서만 열리며, 나중에 파일이 바뀌면 문서에 기록한 해시와 시각을 먼저 대조한다.
